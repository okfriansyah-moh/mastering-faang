# Mastering FAANG

A multi-language practice repository for core coding interview patterns often seen in FAANG-style interviews.

## What This Repo Aims To Achieve

- build strong problem-solving fundamentals
- implement the same problem in multiple languages to compare syntax and patterns
- practice optimal solutions first, then keep brute-force versions for learning contrast
- create quick-reference explanations for interview review

## Current Problem Set

1. `Two Sum`
2. `Container With Most Water`
3. `Trapping Rain Water`

## Learning Approach

1. Start from the brute-force idea to understand correctness.
2. Derive the optimal approach (hash map, two pointers, and similar patterns).
3. Analyze time and space complexity.
4. Re-implement in another language to reinforce understanding.

## Goal

Turn common interview problems into repeatable pattern recognition so you can explain and code solutions clearly under interview constraints.
